# Java OOP Quiz — 15 Questions

Choose one answer per question.

1. A class is best described as: A) a blueprint B) a running loop C) a package manager D) an output
2. An object is: A) only a comment B) an instance of a class C) a keyword D) a compiler
3. Which modifier commonly hides a field from direct outside access? A) public B) private C) static D) void
4. Encapsulation is mainly about: A) controlling access to state and behavior B) printing output C) deleting objects D) naming files
5. Which keyword creates a subclass? A) implements B) import C) extends D) package
6. Which keyword is used when a class implements an interface? A) extends B) implements C) instance D) super
7. Same method name with different parameter lists is: A) overriding B) overloading C) inheritance D) abstraction
8. Redefining an inherited instance method in a subclass is: A) overriding B) overloading C) casting D) packaging
9. Runtime polymorphism commonly uses: A) overridden instance methods B) comments C) variable names only D) imports only
10. An abstract class can: A) never have methods B) define abstract and concrete methods C) only contain constants D) never be extended
11. A constructor is used to: A) initialize a new object B) rename a package C) print all code D) override every method
12. Can a Java class extend two classes directly? A) yes B) no C) only with `static` D) only with `private`
13. A class can implement: A) no interfaces B) only one interface C) multiple interfaces D) only abstract classes
14. A car has an engine. This is commonly modeled as: A) composition B) overriding C) overloading D) recursion
15. Before claiming code works, you should: A) assume it works B) run and verify it C) delete tests D) trust every AI answer

## Answer key with explanations
1. A — a class defines the structure of objects.
2. B — an object is a class instance.
3. B — `private` restricts access to the declaring class.
4. A — encapsulation controls access to internal state and behavior.
5. C — `extends` declares class inheritance.
6. B — `implements` declares interface implementation.
7. B — overloading changes the parameter list.
8. A — overriding supplies a subclass implementation.
9. A — the actual object's overridden method can be selected at runtime.
10. B — abstract classes can contain both kinds of methods.
11. A — constructors initialize instances.
12. B — Java classes extend one superclass directly.
13. C — a class can implement multiple interfaces.
14. A — a car contains/uses an engine.
15. B — run code and verify results instead of assuming.

Score: 13–15 excellent; 10–12 review missed topics; below 10 revisit the notes and retry.
