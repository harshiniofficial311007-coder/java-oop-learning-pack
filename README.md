# Java Object-Oriented Concepts Learning Pack
**Capstone 43 | Target audience:** Second-year CSE students

## Project question
How can AI help teach OOP ideas (classes, inheritance, polymorphism) with clear examples and exercises?

## Learning outcomes
By the end of this pack, learners should be able to explain classes and objects, encapsulation, abstraction, inheritance, polymorphism, constructors, method overloading/overriding, interfaces, and composition.

## Contents
- `docs/research_summary.md` — initial research summary and sources to verify
- `docs/concept_notes.md` — eight core concepts with analogies
- `docs/uml_diagrams.md` — text UML diagrams
- `docs/checklist.md` — revision checklist
- `examples/` — ten standalone Java examples (each has its own `Main.java`)
- `exercises/exercises_and_solutions.md` — 20 exercises with solutions
- `quiz/quiz_and_answer_key.md` — 15-question quiz and answer key
- `docs/prompt_library.md` — prompts used/planned for AI-assisted learning
- `docs/verification_report.md` — fill in after running every example
- `docs/before_after_analysis.md` — learning improvement comparison template
- `presentation/Java_OOP_Learning_Pack.pptx` — seven-slide presentation
- `docs/final_demo_script.md` — short demonstration script

## Run code in a browser
1. Open https://www.onlinegdb.com/online_java_compiler
2. Open one `Main.java` file from an example folder.
3. Copy its full contents into the editor.
4. Click **Run**. Compare the output with the expected output comment.
5. Repeat for all ten examples. Each example is independent; do not paste multiple `Main.java` files together.
