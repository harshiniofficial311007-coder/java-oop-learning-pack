# AI Prompt Library

Record the tool, date, prompt, summary of output, verification source, and corrections for every prompt used.

## Prompt 1 — Concept explanations
“Act as a Java tutor for second-year CSE students. Explain [concept] in beginner-friendly language using a real-life analogy, a short Java example, expected output, and one common misconception. Do not invent references.”

## Prompt 2 — Code review
“Review this Java example for compile errors, incorrect OOP terminology, and misleading explanations. Explain each issue and suggest the smallest correction. Do not claim that code was executed.”

## Prompt 3 — Quiz generation
“Create beginner-level questions about Java OOP covering classes, objects, encapsulation, abstraction, inheritance, polymorphism, interfaces, constructors, overloading, and overriding. Provide an answer key and a one-sentence explanation for each answer.”

## Prompt 4 — Fact verification
“Compare this explanation of [concept] with the supplied Oracle Java or Dev.java documentation. Identify which claims are supported, which are unclear, and what needs correction. Quote only short phrases and provide the source URL.”

## Responsible use
- AI output can be incorrect, outdated, or overly confident.
- Verify code by running it and verify claims against reliable sources.
- Keep your prompts and corrections in this file.
- Do not claim that AI output was verified until you have actually checked it.
- Disclose AI assistance according to your college's policy.
