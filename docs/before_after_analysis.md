# Before-and-After Learning Analysis

Use this template to compare understanding before and after studying the learning pack.

## Method
1. Answer the 10-question self-check before studying.
2. Study the concept notes and run the examples.
3. Answer the same questions again without looking at the notes.
4. Record your actual scores and reflect on any mistakes.

| Measure | Before learning | After learning | Evidence |
|---|---:|---:|---|
| Self-check score out of 10 | Fill in | Fill in | Attach/describe answers |
| Concepts explained without notes | Fill in | Fill in | List concepts |
| Java examples run successfully | 0 or actual count | Actual count | Verification report |
| Most confusing topic | Fill in | Fill in | Reflection |

## Reflection prompts
- Which concept was most difficult before the project?
- Which example helped you understand it?
- What mistake did you correct?
- What would you improve in this learning pack?

Do not invent scores or learner feedback. If only you completed the assessment, describe it as a self-assessment, not a study involving other students.
