# Java OOP Revision Checklist

Mark each item only after you can explain it in your own words.

- [ ] I can distinguish a class from an object.
- [ ] I can identify fields, methods, and constructors.
- [ ] I can explain encapsulation and why fields are often private.
- [ ] I can explain abstraction using an interface or abstract class.
- [ ] I can write a subclass using `extends`.
- [ ] I can implement an interface using `implements`.
- [ ] I can distinguish method overloading from method overriding.
- [ ] I can explain runtime polymorphism.
- [ ] I can describe composition and when it is useful.
- [ ] I can compile/run all ten examples and explain their output.
- [ ] I have checked code and facts against reliable sources.
- [ ] I have recorded actual test results and corrections.
